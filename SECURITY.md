# Security Policy

## Reporting a Vulnerability

Report suspected vulnerabilities privately to
[tom@inflatablecookie.com](mailto:tom@inflatablecookie.com).

Please include:

- the affected package, crate, component, or version
- steps to reproduce the issue
- the expected impact
- any known mitigations
- whether the issue has been disclosed elsewhere

Do not open a public issue for an undisclosed vulnerability. You will receive
an acknowledgement after the report is reviewed, followed by remediation and
disclosure guidance appropriate to the issue.

## Supported Versions

Poodle is currently a pre-1.0 source preview. Security fixes target the latest
revision of the active branch. Older snapshots and unreleased package versions
are not maintained separately.
