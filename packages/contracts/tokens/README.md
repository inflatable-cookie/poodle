# poodle-tokens

Generated Rust bindings for Poodle's canonical design tokens and themes.

The crate exposes typed semantic token identifiers plus theme, density, and
control-size data used by native adapters. Generated values originate in
`packages/tokens`; this crate must not become a second token source.

This crate is a pre-1.0 source preview and is not yet published to crates.io.
