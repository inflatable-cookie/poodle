**Breaking in 0.5.** Poodle now uses subtle filled controls, tonal surfaces,
neutral selection, and system fonts by default. Button, TextInput, PageHeader,
SidebarNav, Dialog, and DataTable use the shared type scale. The `quiet` style
name and `@inflatable-cookie/poodle-core/tokens/style-quiet.css` are removed.
Remove that import and use the base token stylesheet. Remove
`data-style="quiet"` or change it to `data-style="default"`.
