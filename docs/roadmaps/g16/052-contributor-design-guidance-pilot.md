## Goal

Materialize and run one finite, Svelte-only matched pilot for a compact
repository-local contributor router with `frame`, `build`, and `check` routes.
Measure first-attempt composition value without creating public guidance, a
permanent evaluation platform, a model judge, or a cross-runtime claim.

## Fixed Pilot

- Router attachment is the only condition difference. It routes to existing
  Poodle authority and narrow Effigy checks; it adds no independent rules.
- Three in-set scenarios: form/validation, browse/detail, workstation shell.
  One hidden picker holdout. Two independent trials per condition/scenario:
  16 first attempts total.
- Freeze and digest router, prompts, fixtures, checks, rubric, thresholds,
  settings, repository/package state, viewport, theme, density, and network
  posture before output exists.
- Use blind neutral run IDs, randomized conditions, two calibrated human
  reviewers, separate semantic/accessibility/mechanical/composition tracks,
  and the exact arithmetic and invalidation laws from the packet.
- Promotion requires every predeclared score, lift, non-regression, mechanical,
  blocker, and reviewer-conclusion gate. Thresholds cannot move after results.
- Use synthetic data and isolated runs. Sanitized raw output stays outside
  canonical source through verdict plus 90 days; compact manifest, digests,
  scores, notes, correction ledger, and verdict remain.

## Ordered Work

1. Author the smallest candidate router and the exact pilot brief, prompts,
   fixture identities, checks, rubric, anchors, manifest, randomization, and
   retention plan. Obtain the packet-required Poodle-core and Northstar-owner
   freeze approvals before generation.
2. Calibrate reviewers, run the 16 blind first attempts, and invalidate/rerun
   only complete matched scenario blocks under the fixed law.
3. Score semantic, accessibility, mechanical, and composition tracks
   separately. Run the hidden holdout after router digest freeze.
4. Record promote/revise/reject exactly from the predeclared rule. Route any
   accepted corrections to their canonical owner; do not ship generated pages.

## Acceptance

- Every run is reproducible from immutable sanitized manifest data and differs
  only by router attachment.
- Guided outputs have zero semantic, behavior, or accessibility blockers; no
  mechanical or composition score hides such a blocker.
- Reviewer calibration, rescore, N/A, aggregation, invalidation, and holdout
  rules are applied exactly.
- The verdict is mechanically derivable from locked scores and thresholds.
- No consumer guide, public `design.md`, permanent harness/selector, generated
  product page, token/class system, runtime implementation, model judge, or
  cross-runtime claim enters canonical Poodle source.

## Review Oracle

| Invariant | Smallest counterexample | Required proof |
| --- | --- | --- |
| Router is the only treatment | prompt or settings differ by condition | matched block invalidates |
| First attempt stays first | reroll or operator patch before grading | both conditions for scenario rerun from new revision |
| Blockers cannot hide in score | guided semantic failure with high composition | promotion stops |
| Reviewer disagreement is bounded | two-point dimension gap persists | scenario is inconclusive |
| Thresholds are immutable | owner lowers lift after seeing results | manifest/digest mismatch rejects verdict |
| Transfer is real | in-set passes, holdout regresses | no promotion |

## Writable Scope

One repository-local candidate router, one bounded pilot brief/manifest, and
one compact execution log/evidence record; ignored external raw artifacts; this
card; new papercuts. Do not edit component contracts or implementations,
packages, public docs, permanent selectors/harnesses, releases, workflows,
consumers, or visual/parity evidence.

## Validation

Run the frozen scenario-specific Effigy checks, manifest/digest and score-
arithmetic validation, `effigy docs:lint`, `effigy docs:check`, and `git
diff --check origin/main...HEAD`. No windowed/native-visual or release selector
is authorized.

## Stop Conditions

Stop on authority conflict, treatment leakage, invalid matched block, privacy
contamination, ungradeable scenario, persistent reviewer disagreement,
post-result threshold change, or any need for public/productized guidance.

## Continuation

Promote only a passing router. A revise verdict requires a newly frozen full
matched rerun. Reject closes the candidate without replacing canonical Poodle
authority.
