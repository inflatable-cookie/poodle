Status: active

## Context

`g09` began as the architecture-unification generation.
That original tranche is complete, but the generation remains open because GPUI still has substantial remaining work before it can be treated as genuinely finished.

This means `g09` now serves two purposes:

- preserve the completed `g09.001` through `g09.008` foundation work
- hold the continued GPUI execution program until a real closeout is reached

## Current State

- the original `g09.001` through `g09.008` work is complete
- GPUI remains the active renderer focus
- additional milestones still need to be added because the remaining workload is larger than the original closeout implied

## Working Rule

- treat existing `g09.001` through `g09.008` files as completed foundational work
- add new `g09` milestones for remaining GPUI implementation, compliance, parity, and closeout tasks instead of pushing unfinished GPUI work into a later generation
- do not start `g10` until `g09` has an explicit extended closeout path

## Replacement Scope

`g10` is the next generation and should stay Jetstream-focused.
Any remaining GPUI work belongs here in `g09`, not in a removed `g11`.

## Next Task

Extend `g09` with the remaining GPUI milestone set needed to cover the unfinished work still in the codebase, then execute that continuation before opening the Jetstream-focused `g10` track.
