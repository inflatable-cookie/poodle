# g13.015 Generated Contracts, Registries, And Parity Evidence

Status: closed — superseded by the `g13.008` **revise** verdict
(`docs/roadmaps/g13/pilot-verdict-evidence.md` §7–8). This milestone describes
family-by-family migration to a generative model the verdict declines. It is
retained as evidence and is **not executable**. The replacement runway is
`g13.017`–`g13.020`.
Owner: Poodle core
Depends on: `g13.009`, `g13.014`

## Objective

Replace inventory-based parity claims with evidence derived from shared
definitions and executed runtime fixtures.

## Scope

- Generate contract tables, prop/event/slot schemas, recipe inventories,
  registries, specimen matrices, accessibility expectations, and capture IDs.
- Check authored extensions, missing capabilities, placeholder renderers,
  unexecuted scenes, and generated drift.
- Keep prose rationale and runtime notes hand-authored around generated facts.

## Acceptance

- A missing or inert runtime implementation fails parity even when registered.
- Contract, source, generated artifact, and preview inventories agree.
- Generated documentation is deterministic and clearly marked.

## Next

`g13.016` proves source-consumed packages and closes the generation.
