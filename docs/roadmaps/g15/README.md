# g15 — Embedded Slider Controls

Status: completed

This generation corrects the dense scalar-control boundary discovered after
the audio-family closeout. Slider and RangeSlider gain embedded, core-driven
variants with explicit unipolar/bipolar geometry. ModMatrixGrid then composes
that primitive instead of owning a second slider implementation.
