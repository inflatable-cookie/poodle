# Research

Status: reference
Updated: 2026-08-09

Research records the comparisons and source material that informed Poodle's
architecture. It is useful when revisiting a decision, but it is not the source
of truth for current package shape or operator guidance.

## Find Research

- [Master index](master-index.md) — original research programme and coverage
- `source-hubs/` — notes about external systems such as GPUI, Bits, and
  Underlay
- `value-tracks/` — topic research such as tokens, accessibility, overlays,
  forms, and cross-framework contracts
- `translation-memos/` — findings promoted toward architecture
- `specimen-dossiers/` — focused case studies
- [Research-to-architecture cross-reference](research-to-architecture-crossref.md)
  — links findings to decisions

## Authority

Research is point-in-time evidence. External APIs and recommendations may have
changed since a document was written. For current behavior, prefer:

1. [architecture](../architecture/README.md)
2. [specs](../specs/README.md)
3. [component contracts](../contracts/components/README.md)
4. current implementation and generated artifacts

Promote a durable finding into architecture or a spec before treating it as a
repository rule.
