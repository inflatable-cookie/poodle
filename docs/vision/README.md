# Vision

Status: active
Updated: 2026-08-09

Poodle's vision defines the stable product boundary: one documented component
and token system across web and native renderers, without absorbing
application-specific UI.

Read [001 Poodle Vision](001-poodle-vision.md) for the product promise, scope,
ecosystem boundaries, and success criteria. Architecture documents explain the
current implementation; roadmaps contain delivery sequencing.
