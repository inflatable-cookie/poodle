# 0.4.6 — 2026-09-27

`0.4.6` is an additive patch candidate with no breaking API change. Peer ranges
stay `svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Svelte and React `ListCard` accept an optional `eyebrow` — text, or an
  `eyebrowContent` snippet/node — rendered above the title in the card body, so
  mixed lists can show a family or category name on each card without composing
  an external Eyebrow. The eyebrow never changes the card's accessible name.
  This is web-admitted; the portable spec and GPUI mapping follow a later
  native evidence repin.
- Svelte and React `Pill` accept `dismissible` and `dismissLabel`.
  `dismissible` renders a trailing native `<button class="poodle-pill__dismiss">`
  whose accessible name comes from `dismissLabel` (default `"Dismiss"`); a
  click fires `onDismiss`. Default rendering and DOM are unchanged when
  `dismissible` is unset. This is web-admitted; the portable spec follows a
  later native evidence repin.
- Svelte and React `SidebarNavItem` accept `contextMenuItems` and
  `contextMenuAriaLabel`, opening the shared `ContextMenu` from a right-click
  or `ContextMenu`/`Shift+F10`. `onContextAction(itemValue, actionValue)`
  reports the nav item and the chosen menu row. Unset items keep their existing
  link/button semantics. This is web-admitted; the portable spec follows a
  later native evidence repin.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.6 <0.5`.

## Downstream checks

- Use `ListCard.eyebrow` / `ListCard.eyebrowContent` for card family labels.
  Check the eyebrow renders above the title and the card's accessible name is
  unchanged.
- Replace wrapping Button dismiss controls in Pill filter chips with
  `dismissible` and a specific `dismissLabel`. Check the dismiss button is
  keyboard focusable, carries its own accessible name, and fires `onDismiss`.
- Move saved-view row actions from a detached wrapper to
  `SidebarNavItem.contextMenuItems` with `contextMenuAriaLabel`. Check
  right-click and `ContextMenu`/`Shift+F10` open the same menu and that
  `onContextAction` reports the correct item and action.
- Refresh consumer lockfiles and verify they resolve core `>=0.4.6 <0.5`.
- The release candidate certificate must build, pack and source-free-install
  the core and Svelte archive set.

## Candidate boundary

This note records the `0.4.6` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission and windowed conformance are outside this patch.
