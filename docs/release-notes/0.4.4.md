# 0.4.4 — 2026-09-27

`0.4.4` is an additive patch candidate with no breaking API change. It
supersedes `0.4.3`, which was never published. Peer ranges stay
`svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Svelte and React `Text` and `Code` accept `wrap="normal" | "anywhere"`
  (default `normal`). `anywhere` applies `overflow-wrap: anywhere` so long
  identifiers can break inside the element. Unset and `normal` leave current
  wrapping unchanged. This is web-admitted; the portable spec and GPUI mapping
  wait for a later native evidence pin.
- Svelte and React IconButton forward host `data-*` attributes to the root
  button.
- Workspace JavaScript dependencies refresh to their newest compatible
  releases. Notable runtime moves: `lucide-static` 1.48.0 (shipped default icon
  set; `trash` is an additive export and `trash-2` remains an alias),
  `@codemirror/*` and `@lezer/highlight` patches, and root `react` /
  `react-dom` 19.3.0. The Svelte build toolchain stays pinned at the published
  5.56.8 peer floor.
- `packageManager` is `bun@1.4.2`; contributors and CI install from that pin.

## Downstream checks

- Recheck long identifiers in Text and Code with `wrap="anywhere"`; they must
  break inside the element. Unset/`normal` wrapping must stay unchanged.
- Recheck IconButton hosts that pass `data-*` attributes; those attributes must
  reach the root button.
- Recheck consumers against the refreshed compatible dependency set, including
  the shipped icon exports and CodeMirror editor integrations.
- Recheck contributor and CI installs against Bun 1.4.2 from `packageManager`.
- The release candidate certificate must build, pack, and source-free-install
  the core and Svelte archive set.

## Candidate boundary

This note records the `0.4.4` npm/web candidate. It replaces the unpublished
`0.4.3` candidate. Core and Svelte are the only publication set. React remains
private. Cargo packages, native evidence, crates.io, Jetstream admission, and
windowed conformance are outside this patch.
