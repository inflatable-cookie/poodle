# 0.4.13 — 2026-10-08

`0.4.13` is a coordinated npm/web and native release under tag `v0.4.13`,
with additive API only. Peer ranges stay `svelte >=5.56.8 <6`, `react` /
`react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Additive: Keyboard `keyLayout` (`"piano"` default, `"equal-rows"`),
  `rowHeightPx` and `scrollOffsetPx`, across Svelte, React, `KeyboardSpec`
  (`with_key_layout`, `with_row_height_px`, `with_scroll_offset_px`),
  `poodle-render` and GPUI.
- Additive: `@inflatable-cookie/poodle-core/icons/geometry-realize` exports
  the test-support `realize(state)` helper for icon-geometry states.
- Internal previews: GPUI and Jetstream accept `--window-bounds`; Jetstream
  accepts `--component`, `--theme` and `--size`, and compiles again. Jetstream
  admission stays deferred.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.13 <0.5`.

## Candidate boundary

native train ships as the tag. crates.io, Jetstream admission and windowed
conformance are outside this release.
