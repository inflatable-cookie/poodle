# 0.1.0 — 2026-07-24

First documented preview release. Moves the public-intent packages off the
unversioned `0.0.0` baseline. Still pre-release: breaking changes may occur in
`0.x` and no `stable` channel exists yet. See the
[versioning rules](../specs/022-packaging-versioning-and-release-channel-rules.md)
and [change-control rules](../specs/044-deprecation-change-control-and-release-channel-operations.md).

This was a source and version baseline, not a registry publication or GitHub
release tag.

## Packages (preview channel)

Npm packages:

- `@inflatable-cookie/poodle-core` 0.1.0
- `@inflatable-cookie/poodle-svelte` 0.1.0
- `@inflatable-cookie/poodle-react` 0.1.0 (experimental)

`@inflatable-cookie/poodle-core/tokens`, `/styles`, and `/icons` are subpath
exports of `@inflatable-cookie/poodle-core`, not separate packages.

Rust contract + renderer crates (version-aligned to the same 0.1.0 baseline):

- `poodle-headless`, `poodle-markdown`, `poodle-specs`, `poodle-adapter`,
  `poodle-events`, `poodle-layout`, `poodle-style`, `poodle-tokens`,
  `poodle-node`
- `poodle-render` — the one component tier, emitting `poodle-node` trees
- `poodle-gpui`, `poodle-gpui-node-backend`
- `poodle-jetstream`

The `poodle-gpui-preview` and `poodle-jetstream-preview` applications remain
internal validation tooling. They are source-accessible but are not registry
packages.

## Changes

### Breaking

- **Theme id renames** (`@inflatable-cookie/poodle-core/tokens`, `@inflatable-cookie/poodle-core/styles`): `light` →
  `iceberg`, `dark` → `eclipse`, `loophole-studio` → `graphite`,
  `high-contrast` → `hornet`. Both the `data-theme="<id>"` attribute values and
  the `@inflatable-cookie/poodle-core/tokens/theme-<id>.css` subpath exports changed; the old
  `theme-light.css` / `theme-dark.css` / `theme-loophole-studio.css` /
  `theme-high-contrast.css` files were removed.
  **Downstream re-check:** update every `data-theme="…"` and theme CSS import to
  the new ids. In-repo file:-linked consumers were already migrated.

- **`poodle-workstation` removed.** The workstation tier shipped bespoke specs
  for shell surfaces. Six of its thirteen (`ActionDiscoveryPanelSpec`,
  `AppHeaderSpec`, `CommandPaletteSpec`, `DockRegionSpec`, `ShellStatusBarSpec`,
  `SplitViewSpec`) duplicated specs `poodle-specs` already owned; the other
  seven (`CommandPaletteShellSpec`, `PanelHeaderSpec`, `PanelSurfaceSpec`,
  `PanelTabsSpec`, `ProjectHeaderSpec`, `SurfaceTabsSpec`, `WorkspaceShellSpec`)
  had no component, no contract and no Svelte counterpart on any target — they
  registered but never drew.
  **Successor:** `poodle-specs` for the six. For the seven there is an explicit
  non-replacement decision: shell surfaces are composites and are assembled from
  existing components rather than shipped as bespoke ones.
  **Downstream re-check:** swap `poodle_workstation::X` imports for
  `poodle_specs::X` on the six; the constructors are unchanged. Anything reaching
  for the other seven was reaching for a spec that produced no output.
  **Removal gate:** `release-operations.json` sets
  `removalGate: "successor-and-generation-delay"` for preview packages, and the
  deprecation was announced within this same generation. The generation delay was
  waived by explicit owner instruction; the successor and migration requirements
  are satisfied above.

### Additive

- **8 new themes** (`@inflatable-cookie/poodle-core/tokens`, `@inflatable-cookie/poodle-core/styles`): `midnight`,
  `nord`, `rose`, `forest`, `solarized`, `cobalt`, `clay`, `meadow` — 12 themes
  total (3 light: `iceberg`, `clay`, `meadow`; 9 dark). Aggregate
  `@inflatable-cookie/poodle-core/tokens/themes.css` loads every theme layer in one import.
- **ThemeSelect** (`@inflatable-cookie/poodle-svelte`, `@inflatable-cookie/poodle-react`): theme picker with swatch
  tiles and an optional modular theme controller; works with or without it.
- **FilterBuilder** (`@inflatable-cookie/poodle-svelte`, `@inflatable-cookie/poodle-react`): generic filter-clause
  popover companion to OrderBy.
- **`@inflatable-cookie/poodle-react`** (experimental): React implementation of the component set,
  held to the same anatomy contracts as Svelte via the parity gate.

### Behavioral

- **Theme tuning** (`@inflatable-cookie/poodle-core/tokens`): `nord` canvas darkened into the
  dark-family range with secondary-text hierarchy restored; `iceberg` accent
  deepened for contrast. All 12 themes pass WCAG AA (text + text-on-accent).
- **Native theme switchers** (`poodle-gpui-preview`, `poodle-jetstream-preview`):
  `ThemePreset` extended so all 12 themes are selectable, matching the
  data-driven Svelte/React previews.

## Change class

Breaking (theme id renames) + additive (themes, components, `@inflatable-cookie/poodle-react`).
