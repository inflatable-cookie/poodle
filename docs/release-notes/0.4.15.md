# 0.4.15 — 2026-11-05

Coordinated npm/web and native patch release under `v0.4.15`. Behavioral fixes
and internal tooling changes; no new component API or breaking migration.
The release includes the entire range after `v0.4.14`, through the reviewed
submenu repair merged at `7b14b6cd257b9f53fe6ad4f3602e403453e68e85`.

## Changes

- Behavioral: Svelte and React Menu/ContextMenu cascading flyouts flip and
  clamp to viewport bounds, track the owning row on scroll, and retain
  recursive keyboard focus, pointer traversal and dismissal. Internal React
  cascade controls remain private.
- Behavioral: GPUI preview outer and content bounds agree; root motion policy
  reaches native specimens and compatibility builders. AX proof waits for its
  window title at creation.
- Internal: specimen-only web/native capture modes and common framing;
  Oxide-managed Rust validation, Effigy task and Jetstream argument routing,
  pinned Svelte type checking, and Nucleus worktree setup.
- Root, core, Svelte, private React and all Rust versions move together.
  Svelte and React require core `>=0.4.15 <0.5`. Existing peer ranges remain.
