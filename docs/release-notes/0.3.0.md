# 0.3.0 — 2026-09-05

`0.3.0` is the published preview-channel release from the certified `v0.3.0`
tag. `0.2.3` was prepared but unpublished; `0.2.4` is skipped.

This pre-1.0 minor carries a breaking HistoryCenter v3 surface. Consumers
must read this note before adopting the candidate.

## Public-intent delta since v0.2.2

### Breaking

- **HistoryCenter v3 `HistoryEntry`.** `branchCount` is replaced by
  `continuationCount`: the count includes the run's next entry, so a fork
  count is derived as `max(0, continuationCount - 1)`. The v2 `branches` /
  `paths` input is replaced by root `pages` plus host-fed continuation pages.
  Callers migrate to `onNavigateEntry`, `onLoadContinuations`,
  `onLoadContinuationRun`, `onCheckoutContinuation`, and the opt-in
  `onDeleteContinuation` operations.
- **Five HistoryCenter rejection meanings.** `AlreadyAtTarget`,
  `UnknownEntry`, `StaleHistory`, `ProtectedEntry`, and
  `DeletionUnavailable` are the renderer-neutral codes. Hosts map their
  authority results onto these meanings; Poodle does not import authority
  types or decide protocol policy.
- **Root markdown imports.** `AgentMessage`, `AgentPlan`, `AgentPlanRecord`,
  `AgentTranscript`, and `MarkdownEditor` are no longer exported from the
  Svelte or React package root. Import them from `/markdown`. Direct Svelte
  component subpaths and matching React component entries remain available.
  No compatibility alias or silent fallback is provided.

### Additive and behavioral

The candidate inventories the public-intent work accumulated after immutable
`v0.2.2`, including:

- triggerless `ContextMenu` composition (`trigger={false}`), prepared as
  `0.2.3` but not published;
- same-document, cross-window, and opaque external-file drag-and-drop bridges,
  plus Tree reorder authority;
- TimeInput and NumberInput committed-value/raw-draft contracts and
  continuous Knob, Fader, and XYPad controls;
- shared motion policy, EditableLabel draft/commit behavior, block
  Slider/RangeSlider appearance, and same-id Toast update behavior; and
- compiled, source-free web distributions for core, Svelte, and private React,
  with installed browser/SSR and declaration certification.

## Downstream checks

- Update root Svelte/React markdown imports to `/markdown`.
- Update HistoryCenter callers to `pages`, `continuationCount`, the flat
  visible-row model, and host-owned continuation operations. Do not reintroduce
  `branchCount`, v2 `branches`/`paths`, recursive renderer logic, or an
  authority dependency.
- Treat rejection codes as distinct outcomes. In particular, stale history,
  protected entries, and unavailable deletion are not `UnknownEntry`.
- Consume compiled package archives only after the separate candidate
  certification and publication gates pass. React remains validation-only.

## Publication boundary

publication, GitHub release, Loophole change, Jetstream admission, or
