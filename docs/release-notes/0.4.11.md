# 0.4.11 — 2026-10-06

`0.4.11` is a patch candidate with one fix and no API change. Peer ranges stay
`svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Web drag and drop commits a drop released away from its handle (fast or
  imprecise drops). Browsers can deliver `lostpointercapture` before
  `pointerup`; a capture lost after the button is released now counts as the
  release. A capture lost while the button is held still cancels. Applies to
  every component on the shared drag controller in Svelte and React.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.11 <0.5`.

## Downstream checks

- Remove any retry or workaround for drags that occasionally did not drop,
  and check fast drops released off the handle reorder every time.
- Refresh consumer lockfiles and verify they resolve core `>=0.4.11 <0.5`.
- The release candidate certificate must build, pack and source-free-install
  the core and Svelte archive set.

## Candidate boundary

This note records the `0.4.11` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission and windowed conformance are outside this patch.
