# 0.4.1 — 2026-09-13

`0.4.1` is the accepted Poodle web UX patch after the `0.4.0` release. It
contains additive editor presentation controls and behavioral corrections to
the Slider family, editor specimens, and tooltip focus handling. It has no
breaking API change.

## Public-intent changes

### Added

- `CodeEditor` accepts `size` and `sizeRole` in Svelte and React. Its text,
  gutters, controls, and chrome resolve from the explicit value or the shared
  `UiPresentation` size axis. Existing `density` input now affects the complete
  editor presentation consistently.
- `RichTextEditor` accepts `size`, `sizeRole`, and `density`.
  `RichTextRenderer` and `MarkdownRenderer` accept `size` and `sizeRole`.
  Rendered prose, editor text, and toolbar controls follow the resolved axes.

### Fixed

- Slider and RangeSlider block geometry keeps normal thumbs inset, offsets
  range thumbs only for collision resolution, handles endpoint and track-click
  selection correctly, and fills bipolar sliders from the centre. Horizontal
  labels remain stable; values dock to the bar only when measured space is
  safe. Vertical controls retain horizontal thickness, rotate their label, and
  keep values clear of the track.
- Tooltip, IconButton, and Tabs open descriptions for hover and keyboard focus,
  but suppress pointer-triggered programmatic focus such as Dialog and Popover
  autofocus.
- Tabs keeps the measured underline in the tablist's scroll-content
  coordinates, preserving alignment through manual horizontal scrolling,
  programmatic reveal, and resize remeasurement. Vertical scrolling uses the
  corresponding block-axis offset.
- CodeEditor size and density presentation is complete across typography and
  chrome. Rich-text and markdown renderers now scale with the shared size axis.

### Specimen-only UX

- The rich-text image insertion example opens a Dialog over the editor with
  image presets and custom URL, alt, and title fields.
- Slider and editor specimens expose clearer size, density, orientation, and
  formatting comparisons. These specimen changes do not add package API.

## Downstream checks

- Recheck Slider and RangeSlider pointer behavior at endpoints, collisions,
  bipolar values, narrow widths, and vertical orientation.
- Recheck editor typography and toolbar geometry under inherited and explicit
  size/density values.
- Recheck Dialog and Popover autofocus where the focused child owns a tooltip;
  pointer activation must not reveal it, while keyboard focus still must.
- Recheck underlined Tabs after manual scrolling, selected-tab reveal, and
  container remeasurement.

## Candidate boundary

This note records the `0.4.1` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission, and windowed conformance are outside this
patch.
