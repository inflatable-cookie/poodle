# 0.4.5 — 2026-09-27

`0.4.5` is an additive patch candidate with no breaking API change. Peer
ranges stay `svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and
`marked ^18.0.9`.

## Public-intent changes

- Svelte and React `SidebarNavItem` accept optional `endLabel` metadata. It is
  compact, muted and end-aligned for values such as item counts. The accessible
  name stays `label`; `endLabel` is exposed as the item's description. This is
  web-admitted; native admission follows a later evidence repin.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.5 <0.5`.
  CodeMirror, Lezer and TipTap runtime dependencies use caret ranges so a patch
  does not require an exact dependency release elsewhere.

Internal preview and tooling packages remain at `0.0.0`. Candidate-base
admission and the `test:web-scope` per-test cap are internal release tooling;
they change no consumer behavior.

## Downstream checks

- Use `SidebarNavItem.endLabel` for item counts. Check that the item label
  remains its accessible name and the count is announced as its description.
- Applications or wrappers that declare these dependencies directly should
  mirror the package ranges: core `>=0.4.5 <0.5`, with caret ranges for
  CodeMirror, Lezer and TipTap dependencies.
- Refresh consumer lockfiles and verify they resolve the new package and
  dependency ranges.
- The release candidate certificate must build, pack and source-free-install
  the core and Svelte archive set.

## Candidate boundary

This note records the `0.4.5` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission and windowed conformance are outside this patch.
