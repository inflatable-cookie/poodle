# 0.2.3 — 2026-08-30

`0.2.3` is a patch release. It adds triggerless `ContextMenu` composition so
a consumer that already owns context invocation can open a controlled overlay
without a tab-stop button. `menuTransition` still owns open, dismiss, action,
and first-item focus.

There are no product API changes in `@inflatable-cookie/poodle-core`. It
moves so the ecosystem version set stays aligned across one tag.

## What 0.2.3 adds

- `ContextMenu` `trigger` (default `true`). `trigger={false}` omits the
  `role="button" tabindex="0"` host. The consumer supplies controlled `open`
  and `anchorPoint`.
- Svelte is the reference; React matches. Tree specimens use the overlay
  composition.
- Contract: `docs/contracts/components/context-menu.md`.

Change class: additive.

## Downstream checks

- Web consumers install core and Svelte together at exactly `0.2.3`.
- Overlay-only menus should set `trigger={false}` and keep invocation on the
  real target (tree row, list card, canvas).
- Default `ContextMenu` with a slotted trigger is unchanged.
- Do not request `@inflatable-cookie/poodle-react` from npm; it remains
  source-only.
