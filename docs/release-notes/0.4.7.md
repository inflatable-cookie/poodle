# 0.4.7 — 2026-09-30

`0.4.7` is an additive patch candidate with no breaking API change. Peer ranges
stay `svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- The default icon set adds `pin` and `rotate-ccw-clock`, with the alias
  `history` for `rotate-ccw-clock`. HistoryCenter uses them.
- The token schema adds `--poodle-color-surface-hover`
  (`color.surface.hover`); CodeEditor's active line and gutter use it.
- The Svelte package build no longer ships invalid JavaScript for a component
  script with an optional parameter.
- FormLayout and FormDialog submission errors are exposed as an alert with
  their full message.
- A searchable Select opens with every option visible; its committed label no
  longer filters the list on open.
- MessageCenter content fits its popover surface; SplitView pins its seam to a
  fixed secondary pane; multiline TextInput forwards `required`, `inputMode`
  and `enterKeyHint`; controlled Tabs keep focus on the latched transfer.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.7 <0.5`.

## Downstream checks

- If you imported a Svelte component that failed with a syntax error from an
  optional parameter, drop the workaround and check the import resolves.
- Read FormDialog submission errors through the accessibility tree
  (`role="alert"`) instead of screenshots.
- Remove any custom-dropdown workaround for searchable Select opening
  filtered; check that opening a committed Select lists every option.
- Swap HistoryCenter-style stand-in icons for `history` and `pin`.
- Refresh consumer lockfiles and verify they resolve core `>=0.4.7 <0.5`.
- The release candidate certificate must build, pack and source-free-install
  the core and Svelte archive set.

## Candidate boundary

This note records the `0.4.7` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission and windowed conformance are outside this patch.
