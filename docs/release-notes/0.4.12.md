# 0.4.12 — 2026-10-07

`0.4.12` is the first coordinated release of the npm/web and native trains
under one `v0.4.12` tag. Web packages carry no behaviour change. Peer ranges
stay `svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Native crates release by git tag (`v0.4.12`), never crates.io. Procedure:
  `docs/knowledge/contracts/release.md`, Steps (native crates).
- Native, additive: `ToolbarSpec::instance_id` with `with_instance_id`, and
  `poodle_render::toolbar_scope`. Toolbars that share a label (or have none)
  get distinct generated focus ids when named.
- Native, behavioural: GPUI keyboard-activation suppression is scoped per
  window; GPUI composite focus treatment shows only for keyboard-origin focus.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.12 <0.5`.

## Downstream checks

- Native consumers: pin public crates with
  `{ git = "https://github.com/inflatable-cookie/poodle", tag = "v0.4.12" }`
  and depend on `gpui = { package = "gpui-unofficial", version = "=1.22.0" }`.
  A different GPUI release fails to type-check against `poodle-gpui-node-backend`.
- Native consumers with two Toolbars sharing a label: set `with_instance_id`.
- Web consumers: refresh lockfiles and verify they resolve core
  `>=0.4.12 <0.5`.

## Candidate boundary

Core and Svelte are the npm publication set; React remains private. The
native train ships as the tag itself. crates.io, Jetstream admission and
windowed conformance are outside this release.
