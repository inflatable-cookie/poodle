# 0.4.14 — 2026-10-08

`0.4.14` is a coordinated npm/web and native release under tag `v0.4.14` that
adds the `Listbox` composite. Additive only. Peer ranges stay
`svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Additive: `Listbox` composite in Svelte and React, with the core machine
  (`ListboxItem`, `ListboxSelectionMode`, `ListboxOrientation`), and natively
  `ListboxSpec` (`with_items`, `with_selection_mode`, `with_orientation`,
  `with_value`, `with_values`, `with_default_value`, `with_default_values`,
  `with_disabled` and the rest of the contract), `poodle-render` and GPUI.
  Contract: `docs/contracts/components/listbox.md`.
- Fix: Listbox option focus rings are no longer covered by the next row.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.14 <0.5`.
