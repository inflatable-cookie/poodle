# 0.4.9 — 2026-10-05

`0.4.9` is a patch candidate with one behaviour change and no breaking API
change. Peer ranges stay `svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and
`marked ^18.0.9`.

## Public-intent changes

- **Behaviour change:** ContextMenu returns focus to the element that opened
  it when it closes through Escape, outside interaction or item activation,
  with the contract's nearest-surviving fallback. Triggerless menus (such as
  SidebarNav's per-item menus) keep consumer-owned restoration.
- PasswordRequirements rows carry met/not-met accessible labels, decorative
  icons are hidden from assistive technology, and the error is an alert.
- `gpuiMotionPlan` in core applies `translateX` and `translateY`.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.9 <0.5`.

## Downstream checks

- If you restored focus by hand after closing a ContextMenu, remove that code
  and check that focus lands once, on the invoker.
- Read PasswordRequirements state through the accessibility tree rather than
  icon visuals.
- Refresh consumer lockfiles and verify they resolve core `>=0.4.9 <0.5`.
- The release candidate certificate must build, pack and source-free-install
  the core and Svelte archive set.

## Candidate boundary

This note records the `0.4.9` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission and windowed conformance are outside this patch.
