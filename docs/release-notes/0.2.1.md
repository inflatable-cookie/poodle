# 0.2.1 — 2026-08-23

`0.2.1` is the registry-release replacement for `0.2.0`. The `v0.2.0` tag is
retained permanently, but its workflow failed while replacing npm in place and
stopped before release gates, packing, or publication. No `0.2.0` package
reached npm.

This patch carries the same component, contract, token, and renderer payload
documented in the [full 0.2.0 release notes](0.2.0.md). Consumers moving from
`0.1.0` to `0.2.1` must follow every breaking-change and migration instruction
in that note. There are no additional product API changes in `0.2.1`.

## What Publishes

| Package | Version | Disposition |
| --- | --- | --- |
| `@inflatable-cookie/poodle-core` | 0.2.1 | preview-channel npm package |
| `@inflatable-cookie/poodle-svelte` | 0.2.1 | preview-channel npm package |
| `@inflatable-cookie/poodle-react` | 0.2.1 | **experimental — packed and certified, not published** |

Rust crates remain source/tag distribution and carry `0.2.1` in lockstep.
They are not published to crates.io:

- contracts: `poodle-adapter`, `poodle-events`, `poodle-headless`, `poodle-ir`,
  `poodle-layout`, `poodle-markdown`, `poodle-node`, `poodle-specs`,
  `poodle-style`, and `poodle-tokens`;
- composition: `poodle-render`;
- backends: `poodle-gpui`, `poodle-gpui-node-backend`, and
  `poodle-jetstream`.

Jetstream remains program-deferred.

## Fixed

- The release workflow now installs the reviewed npm `12.0.2` CLI into an
  isolated runner prefix and places that binary on subsequent-step `PATH`.
  It no longer mutates the npm installation that is executing the install.
- The automation check rejects any return to in-place global npm replacement
  and requires the isolated pinned CLI path.

## Downstream Checks

- Install core and Svelte together at exactly `0.2.1`.
- Re-run the migration and behavioural checks listed in the
  [0.2.0 release notes](0.2.0.md).
- Do not request `@inflatable-cookie/poodle-react` from npm; it remains
  source-only.
