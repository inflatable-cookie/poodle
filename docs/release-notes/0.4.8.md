# 0.4.8 — 2026-10-04

`0.4.8` is an additive patch candidate with no breaking API change. Peer ranges
stay `svelte >=5.56.8 <6`, `react` / `react-dom >=18`, and `marked ^18.0.9`.

## Public-intent changes

- Tabs `layout="fill"` works inside a flex or grid parent without a definite
  block size.
- Tabs accept `panelScroll="panel" | "content"` (default `"panel"`) to choose
  the scroll owner.
- New Tabs tokens: `--poodle-tabs-gap`, `--poodle-tabs-list-padding`,
  `--poodle-tabs-list-background`, `--poodle-tabs-list-border`, defaulting to
  the previous rendering.
- Every Tabs part carries a contracted `data-part`; the measurement list
  carries `data-measure="true"`.
- Svelte and React require `@inflatable-cookie/poodle-core >=0.4.8 <0.5`.

## Downstream checks

- Replace `:global` overrides of `.poodle-tabs` sizing and panel overflow with
  `layout="fill"` and `panelScroll`; check exactly one scroll container.
- Replace overrides of the Tabs root gap and list chrome with the new tokens.
- Replace queries on `.poodle-tabs__*` classes with `[data-part=…]`, and
  exclude the measurement list with `[data-measure="true"]`.
- Refresh consumer lockfiles and verify they resolve core `>=0.4.8 <0.5`.

## Candidate boundary

This note records the `0.4.8` npm/web candidate. Core and Svelte are the only
publication set. React remains private. Cargo packages, native evidence,
crates.io, Jetstream admission and windowed conformance are outside this patch.
