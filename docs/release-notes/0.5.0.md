# 0.5.0 — 2026-11-28

Coordinated npm/web and native release under `v0.5.0`. The low-noise style is
now the default and the old look is gone. This note is also the migration guide
from `0.4.x`.

The release includes the entire range after `v0.4.16`, through
`f9b7623b6c44d4941ed95c087251e3f0f42398ee`.

## What web consumers must do

1. **Raise your version ranges.** A `0.4` range does not pick up `0.5.0`. Move
   `poodle-core` and `poodle-svelte` together.
2. **Remove the `quiet` stylesheet import.**
   `@inflatable-cookie/poodle-core/tokens/style-quiet.css` no longer exists.
   Load the base token stylesheet,
   `@inflatable-cookie/poodle-core/tokens/styles.css`.
3. **Remove `data-style="quiet"`**, or change it to `data-style="default"`. The
   `quiet` style no longer exists.
4. **Update `splitTokenInput` calls.** It now takes one list of separators:

   ```ts
   // before
   splitTokenInput(raw, /[,;]+/, ",;");
   // after
   splitTokenInput(raw, [",", ";"]);
   ```

   Every character is a literal separator, so list each one. An empty list
   disables splitting.
5. **Add `homebrewFormula` to exhaustive switches** over `InstallManager`. Its
   upgrade command is yours: `brew upgrade <package>`, without `--cask`.
6. **Check each app by eye.** The look changes.

## What looks different

- Controls have subtle fills, surfaces are tonal and selection is neutral
  instead of accent-coloured.
- The default fonts are system sans and mono, no longer Inter, SF Pro Display
  or IBM Plex Mono. To keep a font, set `--poodle-font-sans` or
  `--poodle-font-mono`.
- Button, TextInput, PageHeader, SidebarNav, Dialog and DataTable use the shared
  type scale.
- Text-like controls rest transparent and fill on hover and press: links and
  breadcrumbs, nav and menu items, options, list, tree and table rows, tabs,
  ghost and toolbar icon buttons, disclosure triggers, and close, copy and
  remove buttons. Value-holding controls keep their resting fill. New
  `--poodle-recipe-*-hover-fill` and `-active-fill` hooks cover many of them.
- Several fallback values inside component CSS are gone. A custom token setup
  that skips the base token stylesheet can lose fills and type styling.

If you used `quiet` in `0.4.16`, the new default is that look plus the
hover-only fills above.

`--poodle-color-*` names are unchanged and stay the public contract. Later
`0.5.x` releases will change the look again (type scale, theme model) without
renaming anything.

## Behaviour changes

- Focus traps wrap correctly when focus is on the modal surface or outside the
  focusable list. They include fixed-position elements, editable regions and
  `summary`, and skip elements that cannot be tabbed to.
- Escape no longer dismisses a layer during IME composition, or when an earlier
  handler called `preventDefault()`.
- The date, date range, date-time, date-time range and colour pickers use the
  shared dismiss stack, so Escape inside a Dialog closes one layer at a time.
- When a host declines or fails to prepare a cross-window transfer or file
  export, a drag with the pointer still down carries on as the same local
  session. The source no longer gets a `preparation-declined` or
  `preparation-failed` `onDragEnd` first. `dragSessionTransition` accepts an
  optional `transport: "local"` for this; without it, both events still cancel.
- Rejected drag cancellations no longer escape as unhandled errors.
- `updateDownloadLabel` clamps progress to `0–1`.
- Theme settings given as `null` now match omitted ones: both use the default,
  without a clamp report.
- `treeVirtualWindow` stays within the row count when scrolled past either end.

## Dependencies

Svelte and React require core `>=0.5.0 <0.6`. Peer ranges are unchanged. Their
runtime ranges move up:

- `@codemirror/commands` `^6.11.2`, `@codemirror/language` `^6.13.1`,
  `@codemirror/search` `^6.7.3`, `@lezer/highlight` `^1.2.5`
- `@tiptap/core`, `@tiptap/pm`, `@tiptap/extensions` and the
  `@tiptap/extension-*` packages Poodle uses: `^3.35.1`

The bundled icons now come from Lucide 1.57.0, with the same icon names.

## Native crates

Pin the crate set together to `v0.5.0`. `gpui-unofficial =1.22.0` is unchanged.
The new look is not yet applied by the native renderer; the generated per-role
font-family constants now name system stacks.

### Removed: the Jetstream backend

GPUI is the one native backend. `poodle-jetstream`, its preview and
`RuntimeTarget::Jetstream` are gone. Jetstream hosts stock GPUI and renders
Poodle components through it.

### Native fixes and additions

- GPUI continues a declined or failed drag preparation as a local drag.
- GPUI consumes an Enter that a submit handler takes: it no longer propagates or
  fires a second click on key-up.
- Controlled text, number, code and select inputs can receive ordered intents
  (`apply_*_intent` reducers), so several inputs before a repaint do not use
  stale state.
- `LogListSpec` keeps the newest rows at its cap.
- Slider and range slider values order and clamp correctly; grid `repeat()` is
  capped at 64 tracks.
- Tight Markdown lists keep leading emphasis, strong text and links.
- The tree window stays within bounds, and key activation without a key-format
  adapter is rejected instead of panicking.

## Candidate boundary

Core and Svelte are the npm publication set. React stays private; native crates
stay `publish = false` and ship by the coordinated git tag. No crates.io
publication or windowed conformance.
