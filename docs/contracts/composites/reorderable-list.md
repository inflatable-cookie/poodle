# ReorderableList

**Deprecated:** This component has been consolidated into [EditableList](./editable-list.md).

`ReorderableList` is preserved as a backward-compatible re-export. New code should use `EditableList` directly. The `EditableList` contract contains the full specification for all features previously split between EditableList and ReorderableList, including drag-and-drop reordering, workflow chrome, windowing, add/remove, and all props.

See [editable-list.md](./editable-list.md) for the canonical contract.
