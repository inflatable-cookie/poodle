### Exact Public And Content Surface

```ts
type SliderAppearance = "track" | "block";

// both components
appearance?: SliderAppearance; // default "track"
direction?: "ltr" | "rtl";    // default "ltr"

// Slider
visibleLabel?: string | null;
formatVisibleValue?: (value: number) => string;

// RangeSlider
visibleLabel?: string | null;
formatVisibleValue?: (value: number, thumb: "lower" | "upper") => string;
formatVisibleRange?: (lower: number, upper: number) => string;
```

- `appearance` is orthogonal to `variant`. Omission preserves today's anatomy,
  callbacks, values, and styling.
- Formatter inputs are normalized, bounds-guarded, step-snapped values. Default
  endpoint text is `String(value)`; default range text joins resolved lower and
  upper text with `" – "`. Empty label/formatter text omits that item.
- Native specs carry resolved `visible_label`, per-value visible text, and
  combined range text. They never carry formatter closures.
- Visible content never derives from `ariaLabel`, `valueText`,
  `lowerValueText`, or `upperValueText` and never feeds those channels.
- Horizontal geometry mirrors in RTL. Left/Down still decrement and Right/Up
  still increment; direction does not change numeric key meaning.

### Fail-Closed Horizontal-Only Law

- `appearance="track"` keeps today's horizontal and vertical support.
- `appearance="block"` accepts omitted `orientation` or
  `orientation="horizontal"` only.
- `appearance="block"` with `orientation="vertical"` is invalid in Svelte,
  React, shared Rust composition, and GPUI. Reject it before paint/construction.
- Do not coerce orientation, silently fall back to track, or split behavior by
  runtime. If existing runtime APIs cannot express one fail-closed rejection
  without a new public error surface or compatibility path, stop and return to
  the orchestrator.
- Vertical block admission is a later all-runtime contract migration after
  real native RangeSlider axis geometry and mounted evidence.

### Fixed Fit, Interaction, And Paint Laws

- Block fit is all-or-nothing across every non-empty assigned item:
  `available = floor(unoccluded region span - 2 * content inset)`,
  `required = ceil(shaped inline text advance)`, and fit iff
  `available >= required`. Equality fits. Required-minus-one falls back.
- Fallback is one stable noninteractive, accessibility-hidden line immediately
  after the capsule. It never follows a thumb or changes on focus/overlap.
- RangeSlider picks the nearest thumb at pointer-down; exact ties choose lower.
  The chosen thumb owns the whole gesture, clamps at its sibling, and never
  swaps identity. Equal values retain two semantic focus targets.
- Release, cancellation, lost capture, disablement, stale-pointer cleanup, and
  teardown share one idempotent terminal. The first terminal emits one commit
  with the latest accepted value; cancellation does not roll back.
- Every Slider control and each RangeSlider thumb owns a measurable 44×44
  logical-pixel effective target at every size and density. Prove real hit
  rectangles and per-thumb native bounds, not only root or visible-thumb boxes.
- Forced-color roles are: remainder fill/text = `Canvas`/`CanvasText` and native
  canvas/canvas-text; selected fill/text = `Highlight`/`HighlightText` and
  selection/selection-text; handle fill/border = `ButtonFace`/`ButtonText` and
  control/control-border; focus = `Highlight` and focus-highlight; disabled
  text/border = `GrayText` and disabled-content.
- Block value feedback is static under the existing motion policy. Add no new
  role or timing.
