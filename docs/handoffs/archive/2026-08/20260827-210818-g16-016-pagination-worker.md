## Why It Matters

Pagination is a reusable navigation composite used by Underlay-backed lists and
other data surfaces. Its shared Rust implementation already carries the web
authority's page window, variants, page payloads, and composed page-size
Select, but it has no mounted GPUI proof. It also leaves that Select live while
`loading`, even though every page button is disabled.

This lane closes one concrete behavior defect and one measured evidence cell
without changing public APIs, extending the node vocabulary, or absorbing the
larger Select, accessibility, visual, or Jetstream programmes.
