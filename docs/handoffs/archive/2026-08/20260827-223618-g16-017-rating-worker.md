## Why It Matters

Rating is structurally present across the active cohort, but shared Rust still
uses an incompatible integer-era model: concrete values, whole-step default,
legacy precision/read-only fields, and `u32` callbacks. The renderer always
claims radiogroup semantics and cannot express fractional input, nullable
clearing, roving focus, or keyboard behavior.

This lane fixes the interface and behavior together. It uses the existing
native radio, slider, focus, keyboard, scrub, and rebuild channels; it must not
invent another conformance authority or generic interaction framework.
