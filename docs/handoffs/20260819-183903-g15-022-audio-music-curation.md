## What This Thread Was Doing

Poodle's specimen catalogue is being returned to its human-facing purpose.
Earlier conformance work overloaded many `Examples` views with variant and
size matrices. The structural cleanup is complete; this worker owns the next
bounded curation family, the 11 audio and music pages in `g15.022`.

This is one implementation lane and one PR. Start from the exact card and its
parent method. Do not extend the run into the rest of the catalogue.

## Why It Matters

Poodle v0.2.0 needs a complete Svelte roster that people can understand and
adopt. An exhaustive test corpus is useful as evidence, but it is a poor
default specimen page. These pages should quickly show what each audio control
or display is for, how it is normally used, and which distinctions matter.

The work must also preserve the active-runtime teaching contract: Svelte and
React stay paired, while the shared Rust/GPUI page teaches the same evidence
without inventing unsupported native behaviour.
