### Fixed Editing And Terminal Law

- `value` is committed. Web owns `isEditing` and draft internally. Native
  projects committed `value`, optional `draft_value`, and `is_editing`; live
  edits never overwrite committed `value`.
- `onCommit` carries `{ value, previousValue }` in every active runtime.
  Unchanged commits still emit. Cancel never commits.
- `doubleClick` uses pointer double-click plus Enter/Space. `enterOrSpace` uses
  pointer single-click plus Enter/Space. `programmatic` accepts no gesture.
- Enter commits and restores display focus. Escape/cancel cancels and restores
  display focus. Tab, pointer blur, and window blur commit once without
  restoring. Teardown/unmount itself emits neither commit nor cancel.
- External committed-value replacement while editing returns to view on the new
  committed value with no commit. Disablement during edit cancels. A host echo
  of the just-committed value does not restart or cancel a session.
- `selectOnFocus=true` selects all; false places the caret at the end.
  `maxLength` counts Unicode scalar values, not UTF-16 code units.
- Omitted `ariaLabel` resolves from visible `value`, then `emptyText`, then
  `"Edit label"`; display and editor receive the same name.

Portable trim set **T** is Unicode White_Space plus U+FEFF: U+0009–U+000D,
U+0020, U+0085, U+00A0, U+1680, U+2000–U+200A, U+2028, U+2029, U+202F,
U+205F, U+3000, and U+FEFF. Drop the longest prefix and suffix in **T**.
Interior characters stay. U+200B is not trimmed. Paired machines must not call
ECMAScript `String.trim` or Rust `str::trim` as the authority.

### Exact Imperative Web Surface

Svelte exports exactly these component-instance methods:

```ts
export function focus(): void;
export function startEditing(): void;
export function cancelEditing(): void;
```

React exports `EditableLabelHandle` from the component module and package root,
and exports `EditableLabel` through
`forwardRef<EditableLabelHandle, EditableLabelProps>`:

```ts
export interface EditableLabelHandle {
  focus(): void;
  startEditing(): void;
  cancelEditing(): void;
}
```

`focus()` targets the display in view mode and the live input in edit mode.
`startEditing()` ignores `activationMode` but is inert when disabled or already
editing. `cancelEditing()` is inert outside edit mode and otherwise follows the
Escape law. Add no public `commit()`, element getter, controlled draft, or
second handle type.
