## Why It Matters

IconButton is a high-use primitive inside Poodle's native composites. Rust
currently ignores `default_pressed`, cannot emit the resulting pressed value,
drops tooltip text, and has no named mounted behavior evidence. This card
closes those concrete gaps without reopening the NumberInput value-model
decision or inventing another conformance layer.

## Fixed Behavior

- Keep the simple renderer command entry point and add one handler-bundle
  entry point for command plus pressed-change reporting.
- Toggle mode exists when either pressed input is present. Effective state is
  `is_pressed.or(default_pressed).unwrap_or(false)`.
- Available toggle activation emits the inverse state once, then invokes the
  command callback once. Command-only activation emits no pressed change.
- Disabled/loading targets emit nothing and are not sequential focus stops.
- The same target owns role, label, tab position, structured focus ring,
  toggled state, disclosure state, pointer activation, and keyboard activation.
- Explicit tooltip text wins; otherwise non-empty `aria_label` reaches
  `Node.tooltip`. GPUI native tooltip chrome owns timing, placement, and paint.
- The GPUI specimen keeps its existing concise action/toggle feedback through
  the production compatibility/handler path.
- Mounted evidence uses real hit testing, focus, and keyboard dispatch. Direct
  handler calls do not satisfy the card.

## Important Context

- `Node.tooltip`, `NodeA11y.toggled`, button role, tab position, activation,
  and `FocusRing` already exist. Reuse them; a backend change is a stop.
- The Rust renderer is stateless. The host owns the current pressed value and
  rebuilds after `on_pressed_change`; `default_pressed` is its initial seed.
- The web order is pressed-change first, command callback second.
- The existing one-argument `icon_button` is heavily reused by composites.
  Keep it as the normal command helper and implement the richer path beneath
  or beside it; do not mechanically migrate unrelated composites.
- Fixture-local ids may be stamped after render for the mounted driver. Do not
  add a public instance id solely for testing.
- Keep the specimen human-centered: reuse its compact feedback rather than
  adding an exhaustive behavior matrix.
