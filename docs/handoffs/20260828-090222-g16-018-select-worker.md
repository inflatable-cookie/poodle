## Why It Matters

Select is a prerequisite for many Poodle composites, but its behavior currently
drifts across the web pair and the native substrate. The web implementations
duplicate state decisions and incorrectly report freeform keystrokes as value
changes. Rust cannot report query or highlight transitions and its public
handler shape cannot carry one coherent controlled update.

This is the first of two deliberate cards. It makes the semantic and interface
substrate dependable without claiming mounted native parity. The dependent
`g16.019` card will add real native text entry, overlay input, focus behavior,
mounted proof, and the Select ledger move after this API has landed and been
reviewed.
