crumbs and sends the URL, while Svelte and React activate linkless crumbs and

## Fixed Behavior

- A callback target is a crumb that is non-current, non-ellipsis, linkless,
  and has a supplied `on_navigate` handler.
- It invokes the handler exactly once with `BreadcrumbItem.value`.
- `href`, current, and ellipsis crumbs do not invoke the callback.
- Text, icon-plus-label, and icon-only callback crumbs each remain one target.
- The target declares button semantics, sequential focus, pointer cursor,
  accessible name from the label, and the standard focus ring.
- The icon remains decorative. Icon-only presentation must not erase the
  accessible label.
- GPUI shows one compact interactive readout in the existing Basic or Icons
  specimen group.
- Mounted evidence uses real hit testing, focus, and keyboard dispatch. Direct
  handler calls do not satisfy the card.
