## Fixed Behavior

- `spec.current_open()` is the only effective state for paint, conditional
  content, trigger `expanded`, and next callback payload.
- Controlled `open` wins. `default_open` is a host seed, not hidden renderer
  state; callbacks report the next boolean and the host rebuilds.
- The trigger owns button role, accessible label, expanded/controls state,
  stable scoped identity, activation, sequential focus, and structured focus
  ring. The outer shell owns no false disclosure role.
- Open content owns region role and is labelled by the trigger.
- The compatibility wrapper's existing `with_id` must become meaningful. Keep
  the existing renderer entry point non-breaking; an additive identity-aware
  entry point is allowed.
- Disabled triggers are not focus stops, have no activation/key handler, and
  use the not-allowed cursor while root opacity remains.
- Mounted evidence uses real hit testing, focus, and keyboard dispatch. Direct
  handler calls do not satisfy the card.
