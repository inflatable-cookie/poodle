# Poodle documentation

The entry point to Poodle's docs. Consumers start with the developer guides
and component contracts; contributors start with the knowledge index, which
names the one file that owns each topic.

## Adopt Poodle

- [Svelte developer guide](guides/svelte-developer-guide.md) — package setup,
  themes, icons, components, and application integration
- [React package guide](../packages/react/components/README.md) — React
  surface and experimental-package constraints
- [GPUI developer guide](guides/gpui-developer-guide.md) — Rust contracts,
  themes, node rendering, and the GPUI backend
- [Jetstream developer guide](guides/jetstream-developer-guide.md) — paired
  integration for Rust contracts, node rendering, and conversion
- [Application pattern recipes](guides/README.md) — forms, lists, dialogs,
  media workflows, and admin shells
- [Component contracts](contracts/components/README.md) — the source of truth
  for public inputs, states, events, accessibility, layout, and token usage
- [Poodle implementer skill](../skills/poodle/SKILL.md) — an installable agent
  skill that routes a Svelte view requirement to a recipe, a contract at the
  consumer's pinned release tag, and an available specimen
- [Release notes](release-notes/README.md)
