# Evidence

Status: active

This directory holds generated or validated evidence that remains current
across Northstar generation boundaries. Evidence records what was observed; it
does not replace contracts, architecture, or task authority.

- [`nucleus/`](nucleus/) — fixed Nucleus cohort, receipt schemas, M1/A1
  receipts, and the generated parity ledger used by the active switch runway.
- [`releases/`](releases/) — durable release evidence still consumed by local
  package checks.
